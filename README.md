# Chat Live 💬

A lightweight, real-time, embeddable customer support widget for any website.

## Features
- 100% Vanilla JavaScript (No React/Vue required)
- Real-time messaging using Server-Sent Events (SSE)
- Multi-tenant (Supports multiple websites via API keys)

## How to install on your website
Add this single line of code to your HTML:

<script src="https://your-domain.com/widget.js" data-api-key="YOUR_API_KEY"></script>

## How to run the server locally
1. Run npm install
2. Run node server.js
3. The terminal will generate a Site API Key.
4. Go to http://localhost:4000/admin.html to chat with visitors.
